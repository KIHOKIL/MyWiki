# 2026-09-13

## 샌드박스 (Sandbox) 개념 정리

제시해주신 문맥에서 '샌드박스(Sandbox)'는 **외부 통신망이나 시스템과 철저히 분리된 안전하고 격리된 데이터 처리 환경**을 의미합니다.

원래 IT 보안에서 샌드박스는 어린아이들이 모래놀이터(Sandbox) 안에서만 놀도록 하여 밖을 어지럽히지 않게 하는 것처럼, 프로그램이 시스템의 다른 영역에 영향을 미치지 않고 실행될 수 있도록 만든 '격리 공간'을 뜻합니다.

사내 지식 허브(2nd Brain) 구축이라는 이 문맥에서는 구체적으로 다음과 같은 3가지 핵심 역할을 하는 공간을 뜻합니다.

### 1. 데이터 외부 유출 원천 차단 (Data Isolation)
가장 중요한 목적입니다. 사내 기밀문서나 개발 데이터(Jira, Confluence 등)를 AI가 요약하고 분석할 때, 이 데이터가 OpenAI나 Anthropic 같은 **외부 퍼블릭 LLM 서버로 빠져나가지 못하도록 가두는 안전 구역** 역할을 합니다. 샌드박스 안에서만 데이터 연산이 일어나게 하여 '로컬 우선(Local-First)' 원칙을 기술적으로 강제하는 것입니다.

### 2. 에이전트 권한의 엄격한 통제 (RBAC 실행 구역)
AI 에이전트가 임의로 모든 사내 데이터를 뒤지는 것을 막습니다. 샌드박스는 에이전트가 질문을 한 **사용자의 권한(Role)에 맞는 데이터에만 접근**할 수 있도록 통제하는 '보안 검문소' 역할을 합니다. 권한이 없는 데이터는 샌드박스 내부로 아예 들어올 수 없게 만듭니다.

### 3. 시스템 원본 보호
AI 에이전트가 사내 시스템(Jira 등)과 연동되어 작업을 수행할 때, 실수로 원본 데이터를 삭제하거나 훼손하지 못하도록 제한된 읽기/쓰기 권한만을 부여받고 활동하는 '안전한 가상 공간'이 되어줍니다.

---

**요약하자면:**
여기서의 MCP(Model Context Protocol) 샌드박스는 "AI 에이전트가 사내 민감 데이터를 다룰 때, 정해진 권한 내에서만 데이터를 읽고 처리하며 밖으로는 절대 유출하지 못하게 만든 안전한 가두리 환경"이라고 이해하시면 정확합니다.
