# 🎨 멤피스 코퍼레이트 플랫 일러스트 슬라이드 생성 프롬프트

## 🎯 프롬프트 목적 및 개요
테크 기업(Google, Meta, Slack 등)에서 선호하는 **현대적인 플랫 벡터 일러스트레이션(Flat Illustration)과 멤피스(Memphis) 기하학적 패턴**을 결합하여, 밝고 친근하면서도 정돈된 기업용 프레젠테이션 슬라이드 및 인포그래픽을 제작하는 프롬프트입니다.

---

## 📋 프롬프트 원문 (Prompt Template)

```text
1. 주제: 인기 300 Flat illustration / Corporate / Memphis 스타일로, 사용자가 입력한 [{{주제 또는 슬라이드 내용}}]을(를) 한 장의 슬라이드나 인포그래픽으로 변환한다.
2. 구도: 제목, 주인공, 핵심 포인트, 보조 도해를 자연스러운 읽기 순서로 배치한다. 주요 정보 블록은 최대 5개로 제한하고 화면을 과하게 채우지 않는다. 위치와 레이아웃은 자연스러운 문장으로 설명한다.
3. 빛: 화면 전체를 밝고 읽기 쉬운 빛으로 정리하고, 문자와 도해의 대비를 분명하게 만든다.
4. 스타일: 장난기 있는 멤피스 패턴을 활용한 플랫 벡터, 현대적 테크 회사 스타일. 물결선, 점, 삼각형, 유기적 블롭(멤피스 요소). 질감과 패턴은 절제된 보조 요소로만 사용한다. 큰 팔다리의 플랫 피규어, 단순화된 오브젝트, 벡터 씬. 부드러운 형태를 써도 좋지만 화면이 유치하게 보이지 않도록 조절한다.
5. 색: 배경: 화이트 또는 매우 연한 파스텔 그레이. 주 텍스트 색상: #3B5998 (코퍼레이트 블루) 강조 색상: #FF6B6B (액센트 레드), #FFD93D (액센트 옐로우), #6C5CE7 (소프트 퍼플). 색채는 친근함을 주되 기업 자료로서의 정돈감은 잃지 않는다.
6. 문자: 화면 속 문자는 짧은 한국어 제목, 숫자, 라벨, 주석만 사용한다. 같은 라벨과 주석은 화면 안에서 한 번만 사용한다. 제목: 오픈 산스, 로보토 또는 모던 기하학적 산세리프. 본문: 읽기 쉬운 본문 서체 구조: 깔끔함, 가독성 중심, 미디엄 웨이트. 숫자 표현: 중요한 수치는 정보의 축으로 읽히도록 정리한다.
7. 한글 가독성: 한국어가 깨지거나 뭉개지지 않도록 신경써서 선명하게 표시해줘.
8. 마감: 표, 도식, 핵심 포인트를 질서 있게 정리한다. 강조는 최소화하고 읽는 속도를 우선한다. 친근한 형태를 허용하되 설명의 흐름은 명료하게 유지한다. 라벨, 제목, 수치의 관계가 즉시 읽히도록 배치한다.
```

## 🔍 프롬프트 8대 구성 요소 분석 및 해설

| 구성 항목 | 설계 의도 및 역할 |
|---|---|
| **1. 주제 (Subject)** | 슬라이드의 전반적인 테마와 핵심 메시지를 규정 |
| **2. 구도 (Composition)** | '최대 5개 정보 블록' 제한을 두어 슬라이드가 빽빽해지는 것을 방지하고 Z자/F자 시선 유도 |
| **3. 빛 (Lighting)** | 높은 명도와 높은 텍스트 대비(Contrast)를 주어 프로젝터/모니터 가독성 확보 |
| **4. 스타일 (Style)** | 물결, 점, 블롭 등 멤피스 패턴 + 플랫 캐릭터를 통해 IT 테크 기업다운 친근하고 세련된 무드 형성 |
| **5. 색상 (Color Palette)** | `#3B5998`(코퍼레이트 블루), `#FF6B6B`(레드), `#FFD93D`(옐로우) 등 전문적인 HSL 기반 조화 색상 고정 |
| **6. 문자 (Typography)** | 본문 길이를 제한하고 타이틀과 핵심 지표(Metric) 중심 배치 |
| **7. 폰트 렌더링** | AI 이미지/슬라이드 생성 시 폰트 뭉개짐(Artifacts) 방지 가이드 |
| **8. 마감 (Finishing)** | 과도한 장식을 배제하고 정보의 전달 속도(Scannability) 극대화 |

---

## 💡 재사용(Reuse) 방법
- Banana LM, Midjourney, DALL-E, 또는 멀티모달 LLM 슬라이드 생성 도구에 입력 시 `[{{주제 또는 슬라이드 내용}}]` 부분만 원하는 슬라이드의 장별 요약문으로 치환하여 사용하십시오.
