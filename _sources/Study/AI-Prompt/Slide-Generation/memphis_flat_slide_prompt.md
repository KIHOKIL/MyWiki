# 🎨 멤피스 코퍼레이트 플랫 일러스트 슬라이드 생성 프롬프트

현대적인 글로벌 테크 기업(Google, Meta, Slack 등)에서 널리 활용하는 **Corporate Flat Vector Illustration**과 **Memphis 기하학적 패턴**을 결합하여, 밝고 친근하면서도 기업 자료로서의 전문적인 신뢰감을 잃지 않는 한 장의 슬라이드/인포그래픽을 제작하는 표준 프롬프트입니다.

---

## 📋 1. 프롬프트 원문 (Prompt Template)

```text
1. 주제: 인기 300 Flat illustration / Corporate / Memphis 스타일로, 사용자가 입력한 [{{주제 또는 슬라이드 내용}}]을(를) 한 장의 슬라이드나 인포그래픽으로 변환한다.
2. 구도: 제목, 주인공, 핵심 포인트, 보조 도해를 자연스러운 읽기 순서로 배치한다. 주요 정보 블록은 최대 5개로 제한하고 화면을 과하게 채우지 않는다. 위치와 레이아웃은 자연스러운 문장으로 설명한다.
3. 빛: 화면 전체를 밝고 읽기 쉬운 빛으로 정리하고, 문자와 도해의 대비를 분명하게 만든다.
4. 스타일: 장난기 있는 멤피스 패턴을 활용한 플랫 벡터, 현대적 테크 회사 스타일. 물결선, 점, 삼각형, 유기적 블롭(멤피스 요소). 질감과 패턴은 절제된 보조 요소로만 사용한다 큰 팔다리의 플랫 피규어, 단순화된 오브젝트, 벡터 씬. 부드러운 형태를 써도 좋지만 화면이 유치하게 보이지 않도록 조절한다.
5. 색: 배경: 화이트 또는 매우 연한 파스텔 그레이. 주 텍스트 색상: #3B5998 (코퍼레이트 블루) 강조 색상: #FF6B6B (액센트 레드), #FFD93D (액센트 옐로우), #6C5CE7 (소프트 퍼플) 색채는 친근함을 주되 기업 자료로서의 정돈감은 잃지 않는다.
6. 문자: 화면 속 문자는 짧은 한국어 제목, 숫자, 라벨, 주석만 사용한다. 같은 라벨과 주석은 화면 안에서 한 번만 사용한다. 제목: 오픈 산스, 로보토 또는 모던 기하학적 산세리프. 본문: 읽기 쉬운 본문 서체 구조: 깔끔함, 가독성 중심, 미디엄 웨이트. 숫자 표현: 중요한 수치는 정보의 축으로 읽히도록 정리한다.
7. 마감: 표, 도식, 핵심 포인트를 질서 있게 정리한다 강조는 최소화하고 읽는 속도를 우선한다 친근한 형태를 허용하되 설명의 흐름은 명료하게 유지한다. 라벨, 제목, 수치의 관계가 즉시 읽히도록 배치한다.
```

## 🔍 2. 7대 핵심 구성 요소 분석 및 설계 의도

| 번호 | 구성 요소 | 핵심 가이드라인 및 설계 의도 |
| :---: | :--- | :--- |
| **1** | **주제 (Topic)** | `인기 300 Flat illustration / Corporate / Memphis` 스타일을 지정하여 입력된 텍스트를 인포그래픽/슬라이드로 압축 |
| **2** | **구도 (Layout)** | 주요 정보 블록을 **최대 5개**로 엄격히 제한하여 여백을 확보하고 Z자형 시선 이동 흐름 구현 |
| **3** | **빛 (Lighting)** | 화면 전체를 고르게 밝히고 배경과 전경의 높은 대비(Contrast)를 확보하여 프로젝터/디스플레이 가독성 극대화 |
| **4** | **스타일 (Style)** | 물결선, 점, 삼각형, 유기적 블롭 등 절제된 멤피스 요소 + 큰 팔다리의 플랫 피규어를 결합하여 과하지 않은 친근함 부여 |
| **5** | **색채 (Palette)** | **배경**: 화이트 / 연한 파스텔 그레이<br>**주 텍스트**: `#3B5998` (Corporate Blue)<br>**강조색**: `#FF6B6B` (Accent Red), `#FFD93D` (Accent Yellow), `#6C5CE7` (Soft Purple) |
| **6** | **문자 (Typography)**| 짧은 제목, 숫자, 라벨, 주석만 최소한으로 사용하며 중복 라벨 배제. 오픈 산스/로보토 기반의 미디엄 웨이트 가독성 중심 배치 |
| **7** | **마감 (Finishing)** | 과도한 화려함보다 표/도식/핵심 수치의 직관적 연결과 읽는 속도(Scannability) 최우선 정돈 |

## 💡 3. 실제 적용 예시 (Use Case Examples)

### 예시 A: 사내 Group 2nd Brain 아키텍처 슬라이드
> **입력**: `[{{주제 또는 슬라이드 내용}}]` ➡️ `Clang AST 기반 Semantic CodeGraph 인덱서 및 사내 지식 그래프 구축 파이프라인 (3단계: 소스 수집, AST 파싱, MCP 에이전트 연동)`

### 예시 B: 팀 분기 성과 인포그래픽
> **입력**: `[{{주제 또는 슬라이드 내용}}]` ➡️ `모바일 통신 프로토콜 SW 안정화 프로젝트 3대 핵심 성과 (이슈 해결률 98%, 메모리 누수 0건, CI 빌드 시간 40% 단축)`
