# 📝 복합 소스 기반 초보자 맞춤형 해설 보고서 생성 프롬프트

## 🎯 프롬프트 목적 및 개요
어려운 기술 논문, GitHub 리포지토리, 아키텍처 가이드 등 복잡한 소스 문서들을 바탕으로, **초보자나 비전문가도 직관적으로 이해할 수 있는 친근하고 완결성 높은 입문 보고서(블로그/칼럼)**를 작성할 때 사용하는 템플릿입니다.

---

## 📋 프롬프트 원문 (Prompt Template)

```text
{{소스1, 소스2, 소스3...}}의 핵심 내용을 초보자 눈높이에 맞춰 직관적인 비유({{예: 컴퓨터 메모리, 인맥 지도, 자동 청소 로봇 등}})를 사용하여 가장 이해하기 쉽게 풀어쓴 '{{주제}} 입문서'를 생성해주세요.

다음의 내용을 체계적이면서도 무척 알기 쉬운 어조로 구성해 주세요:
1. 서론: {{주제}}가 왜 필요하고, 기존 방식({{기존 한계점}})의 한계는 무엇인지 쉽게 설명
2. {{핵심개념1}}: 컴퓨터나 일상적인 사물에 비유한 메커니즘 설명
3. {{핵심개념2}}: 관계망 및 구조적 차이점을 지도/네트워크 비유로 설명
4. {{핵심개념3}}: 라이프사이클(수집-정리-진화-활용-관리 등)에 대입하여 설명
5. {{융합 아키텍처}}: 핵심 개념들이 하나로 합쳐진 미래형 통합 구조와 시너지를 시각화하듯 서술
6. 실전 활용 시나리오: 실제 도구 연동을 통해 실무 문제를 해결하는 직관적인 시나리오 가이드 제공

전반적으로 기술적인 장벽을 낮추기 위해 일상적인 단어와 친근한 대화체를 적극적으로 사용하고, 핵심 요점을 볼드체로 강조하여 읽기 속도를 높여 주세요.
```

---

## 🔍 프롬프트 구조 분석 및 해설

1. **타깃 독자 및 톤앤매너 지정:**
   - "초보자 눈높이", "친근한 대화체"를 명시하여 난해한 수식이나 전문 용어 남발을 억제합니다.
2. **비유(Analogy) 앵커링:**
   - 추상적인 기술(예: 가상 메모리 페이징, 지식 그래프)을 일상적인 비유(RAM과 디스크, 인맥 지도)로 치환하도록 강제하여 독자의 멘탈 모델 형성을 돕습니다.
3. **6단계 기승전결 구조:**
   - `서론(문제 정의)` → `각론(개념별 분해)` → `종합(융합 아키텍처)` → `실무 적용(시나리오)`으로 이어지는 논리적 흐름을 구축합니다.
4. **가독성 지침:**
   - 볼드체 강조, 단계별 넘버링을 요청하여 슬라이드/영상 대본으로 분할하기 쉬운 텍스트 구조를 유도합니다.

---

## 💡 재사용(Reuse) 방법
- 연구 논문 요약, 기술 블로그 포스팅, 사내 교육 자료 작성 시 중괄호 `{{ ... }}` 안의 변수를 실제 프로젝트 내용으로 바꾸어 LLM(Gemini Canvas, ChatGPT, Claude 등)에 입력하십시오.
