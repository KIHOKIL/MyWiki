SDD가 작동하기 위한 5가지 사고방식 전환

도구를 쥐어줘도 생각이 바뀌지 않으면 과거 방식으로 회귀한다

01Spec First, Code Second

코드를 건드리기 전에 명확한 자연어 스펙을 작성하라. 모호한 프롬프트는 무한 수정 핑퐁의 주범이다.

02Reviewer, Not Author

인간은 더 이상 코더가 아니다. 코딩은 AI에 넘기고, 인간은 아키텍처·엣지케이스·도메인 맥락의 판사가 된다.

03Externalize Mental Context

머릿속 암묵지(패턴, 컨벤션, 의도)를 꺼내 문서화(CLAUDE.md, ADR)하라. 외부화되지 않은 지식은 AI가 알 수 없다.

04Attention on Front-end (Design)

엔지니어 100명 몫을 AI가 코딩하므로 코딩은 더 이상 병목이 아니다. 인간의 시간은 스펙 설계에 80% 쏟아야 한다.

05Closed Learning Loop (복리 성장)

AI의 실패는 환경 개선의 기회다. 실패 원인을 CLAUDE.md 가드레일이나 스킬로 승격시켜 시스템을 업그레이드하라. 50번째 세션은 첫 번째 세션보다 압도적으로 생산적이어야 한다.
