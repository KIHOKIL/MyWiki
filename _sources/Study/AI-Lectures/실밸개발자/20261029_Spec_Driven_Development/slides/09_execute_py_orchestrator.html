scripts/execute.py 오케스트레이터 분석

Preamble 가드레일, 3회 자가교정, 2단계 원자적 커밋

⚙️ execute.py 4대 핵심 메커니즘

1. 가드레일 & 컨텍스트 주입

매 세션마다 CLAUDE.md + docs/*.md + 이전 완료 Step들의 1줄 요약(summary)을 Preamble로 자동 합성

2. 3회 자가교정 루프 (Self-Correction)

AC 실패 시 최대 3회 재시도. 이전 실패 에러 메시지(prev_error)를 다음 프롬프트에 자동 주입하여 스스로 수정

3. 원자적 2단계 커밋 (Atomic Commits)

코드 변경(feat: step N)과 관리 메타데이터(chore: step N output)를 분리하여 Git 히스토리 청결성 유지

4. 명확한 상태 전이 및 차단 감지

pending ➡️ completed, error, blocked. API 키나 수동 작업 필요 시 blocked 상태로 즉시 사용자 개입 요청

# 실행 명령어
python3 scripts/execute.py 0-mvp --push
