그룹장 실무 적용: 임베디드 SW & PHY 계층 SDD

모바일 통신 프로토콜 / PHY Layer C/C++ 하네스 프레임워크 설계

📡 모바일 SW 통신 프로토콜 그룹 맞춤 실무 적용

1. HW 레지스터 맵 기반 C/C++ 임베디드 하네스 구축

신규 모뎀/RFIC 레지스터 맵 CSV를 docs/PRD.md(비트필드, 오프셋)로 정의 ➡️ execute.py가 C 구조체 헤더 생성 ➡️ 읽기/쓰기 인라인 함수 ➡️ QEMU/호스트 단위 시뮬레이션 AC 검증까지 자동화.

2. 3GPP 프로토콜 스택의 계층형 스펙(Hierarchical Spec) 분할

수만 줄의 통신 규격을 통째로 주입하지 않고, Master Spec(전체 아키텍처) 아래 L1 PHY(디코딩), L2 MAC(HARQ), L3 RRC(상태 머신)로 모듈을 분할하여 컨텍스트 압축 없는 정밀 구현.

3. JIRA / 필드 이슈 분석 자동 회고 루프

필드 Drop call 또는 CRC 에러 로그를 분석한 뒤, 일회성 패치로 끝내지 않고 docs/ADR.md 및 CLAUDE.md에 동기화 타이밍 제약 규칙을 영구 반영하여 복리 개선.
