좋은 스펙의 5가지 핵심 요소

스펙은 길 필요가 없다. 이 5가지만 명확하면 직행한다

1. Inputs & Outputs (입출력)

명확한 입력 데이터 구조와 관측 가능한 기대 출력 정의 (예: 프롬프트+이미지 ➡️ 16:9 썸네일 2개)

2. Success Criteria (성공 기준)

정량적으로 측정 가능한 성공 척도 (예: 응답시간 < 2초, 빌드 에러 0개, 테스트 커버리지)

3. Constraints (제약 조건)

보안, 라이브러리 제한, 외부 API 호출 전용 라우트 강제 등 절대 넘지 말아야 할 기술적 경계

4. Scope & Out-of-Scope (범위)

이번 MVP에서 "절대 하지 않을 것"을 명시. AI 특유의 과도한 오버엔지니어링 원천 차단

5. Edge Cases (예외 및 에러 핸들링)

API Rate Limit, 네트워크 단절, 잘못된 사용자 입력 시의 조건부 재시도 및 UI 폴백 매트릭스
