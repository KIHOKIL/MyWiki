# OPIc Study Repository (오픽 시험 대비 체계적 아카이브)

OPIc 시험의 **IH(Intermediate High) ~ AL(Advanced Low)** 달성을 위해 강사별·일자별로 기출 유형, 질문, 모범 답변, 핵심 어휘(Collocations), 그리고 실전 발화 프레임워크를 체계적으로 누적·학습하는 지식 저장소입니다.

## 🎯 OPIc 핵심 출제 유형 (3단 콤보 & 롤플레이)

1. **인물 / 장소 / 사물 묘사 (Description)**:
   - 시제: **현재 시제** 중심.
   - 발화 길이: 1분 ~ 1분 15초 내외.
   - 핵심 전략: 두괄식 주제 제시(M) ➡️ 3단 바디(B) ➡️ 요약(C)의 **MBC 프레임워크**.
2. **과거 vs 현재 변화·비교 (Comparison)**:
   - 시제: **과거 시제 + 현재 시제 대조**.
   - 접속사: While, In the past..., but nowadays..., compared to.
3. **과거 경험 / 기억에 남는 계기 (Past Experience)**:
   - 시제: **단순 과거 + 과거 진행/완료**.
   - 스토리라인: 시간 순서(발단-전개-위기-절정-결말) 및 개인적 교훈/느낌.
4. **롤플레이 (Role-Play & Problem Solving)**:
   - 11번 (정보 문의: 3~4개 질문 던지기), 12번 (문제 상황 설명 및 2~3가지 대안 제시), 13번 (유사 경험).
