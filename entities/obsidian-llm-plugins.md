# Obsidian LLM Plugins

개인 사용자가 복잡한 서버 배포 없이 바로 자신의 Vault를 LLM Wiki처럼 활용하게 도와주는 로컬 기반의 플러그인들입니다.

## 대표 플러그인

### Smart Connections
- **특징:** Vault 내의 노트 간 의미(Semantic) 기반 연결과 검색을 제공합니다.^[extracted]
- **유연성:** 로컬 임베딩 모델을 활용하거나 외부 LLM API를 연동하여 동작할 수 있습니다.^[extracted]

### Copilot for Obsidian
- **특징:** Vault 전체 데이터에 대해 채팅형으로 질의응답(Q&A) 할 수 있게 해줍니다.^[extracted]
- **작동 방식:** 보통 Claude API나 OpenAI API 등을 연결하여 사용합니다.^[extracted]

## 추천 용도
집 PC나 개인 작업 환경에서 가장 빠르게 "개인용 LLM Wiki"를 도입하고자 할 때 1차적으로 추천되는 방식입니다.^[inferred]
